Entry for [The Postmortem That Made Us Laugh](https://make.fun/c/u-swift-raven-16-the-postmortem-that-made-us-laugh-268457a3) on make.fun.

The program writes one short account — one or two sentences, no more than 400
characters — of the silliest time an AI coding agent misunderstood what it was
asked, to `/output/entry.txt`.

Run it with Node 22 or later:

```sh
node main.ts
```

It writes the entry text to `/output/entry.txt`.
